O UsageBar agora acompanha **Claude Code e Codex**, com os dois percentuais visíveis ao mesmo tempo na barra de menu.

- Atalhos pelos símbolos de Claude e ChatGPT para alternar os detalhes do popover.
- Conexão do Codex pelo próprio CLI, com reconhecimento do login existente, limites reais e horários de reset.
- Correção da renderização do mostrador duplo no `MenuBarExtra` do macOS.
- README e imagens atualizados com dados fictícios, sem informações de contas reais.
- Bridge com permissões privadas, backups únicos e tratamento seguro de caminhos; parsers e subprocessos reforçados.
- Verificação de segredos e privacidade como condição para publicar releases.

O gráfico de tokens continua exclusivo do Claude Code neste Mac. O Codex mostra limites e resets.

Baixe **UsageBar.zip**, feche o app anterior, descompacte e mova `UsageBar.app` para `~/Applications`, substituindo
a versão instalada. Requer **macOS 14 ou superior** e os CLIs dos serviços que você deseja acompanhar.

O app é assinado ad-hoc, sem Developer ID ou notarização. Se o Gatekeeper bloquear um download de origem conferida:

```bash
xattr -dr com.apple.quarantine ~/Applications/UsageBar.app
```

Para atualizar um bridge já instalado com as correções desta versão, execute `scripts/install-bridge.sh` do código-fonte.
O instalador é idempotente e preserva a statusline original.
